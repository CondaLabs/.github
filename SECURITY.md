# Security Policy

## Reporting a Vulnerability

We take the security of CondaLabs projects seriously. If you discover a potential security vulnerability, please report it responsibly.

**Please do not disclose security vulnerabilities publicly through GitHub issues, pull requests, or discussions until they have been reviewed and addressed.**

Instead, use GitHub's private vulnerability reporting feature for the affected repository, if it is enabled:

1. Open the affected repository on GitHub.
2. Go to the **Security** tab.
3. Select **Report a vulnerability**.
4. Provide the details of the issue.

If private vulnerability reporting is unavailable, contact the repository maintainers privately through GitHub.

## What to Include

When reporting a vulnerability, include as much of the following information as possible:

- The affected repository and version or commit.
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Its potential impact.
- Any proof-of-concept or relevant technical details.
- Suggested fixes, if you have them.

Please avoid accessing, modifying, or deleting data that does not belong to you while investigating a potential vulnerability.

## What to Expect

After receiving a report, maintainers will:

1. Review the report and attempt to verify the issue.
2. Assess its severity and potential impact.
3. Work on an appropriate fix or mitigation.
4. Coordinate disclosure with the reporter when appropriate.

We will make a reasonable effort to acknowledge reports and provide updates as the issue is investigated. Response times may vary depending on the report and maintainer availability.

## Disclosure

Please allow maintainers reasonable time to investigate and address a reported vulnerability before sharing it publicly.

Once a fix is available, disclosure details may be shared in a coordinated manner.

## Supported Versions

Security support depends on the maintenance status of each project. Check the affected repository's README and release information for currently maintained versions.

Individual repositories may provide additional security instructions or supported-version details.

Thank you for helping keep CondaLabs projects and their users safe.
